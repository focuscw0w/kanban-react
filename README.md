# Kanban Board 

A simple **Kanban Board** web application built with **React**, **Vite**, and **TailwindCSS**.  
It provides an interactive board for managing tasks across multiple columns and subtasks.

## Overview
This project was built as a practice assignment inspired by  
[Frontend Mentor – Kanban Task Management Web App](https://www.frontendmentor.io/challenges/kanban-task-management-web-app-wgQLt-HlbB).  

## Features
- Create, edit, and delete tasks  
- Organize tasks into boards and columns (statuses)  
- Manage subtasks with checkboxes  
- Dark/Light theme toggle  
- Responsive layout for desktop and mobile  
- Sidebar navigation for switching boards
  
## Not Implemented
- Form validations when creating/editing boards and tasks  
- Drag & drop tasks between columns and within a column  
- Persistent storage (e.g., **localStorage** or backend)  
- Full-stack implementation

## Tech Stack
- **React 18** – UI framework  
- **Vite** – fast development build tool  
- **TailwindCSS** – styling  
- **React Context API** – global state management  
- **Custom Hooks** – reusable logic for boards & task
